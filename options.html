Filter settings sync

When enabled, your extraction profiles and auto-export settings are stored as .filter-settings.json inside your remote folder. On each browser start the extension compares timestamps: the newer version wins. You can also sync manually at any time with the button below.

Extraction profiles

One JSON object per site profile. hostnamePattern is a regex tested against location.hostname — first match wins, so keep a catch-all ".*" profile last.
containerSelector: CSS selector to scope extraction (empty = whole page).
excludeSelectors: CSS selectors to skip (e.g. sidebars, nav).
startDelimiters / endDelimiters: literal strings — text before the earliest start match and after the earliest end match is discarded.
maskRules: [{"pattern": "regex", "flags": "g", "replacement": "..."}], applied in order.
